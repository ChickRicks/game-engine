# Hashmap

## Resumo
Precisa da biblioteca `std::collections::HashMap;`. Para criar, usa `let mut foo = HashMap::new();`.Para inserir algo na hashmap, usa `insert()` com a estrutura `foo.insert(chave,valor)`. Para acessar, precisa usar `get()` na estrutura `foo.get(chave)`, retornando o valor. Pode atualizar os valores de uma chave usando o `insert()`.
